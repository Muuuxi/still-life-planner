STILL — STATIC PORTFOLIO DEMO

How to open:
1. Unzip the folder.
2. Double-click index.html.
3. It opens in your default browser. No npm, Node.js, Supabase, login, or internet connection is required.

What works:
- This Week / Next Week agenda
- Weekly calendar (7 AM–11 PM)
- Areas → Projects → Items
- Project progress bars
- Add / edit / delete items
- Mark items complete
- Work Log + automatic weekly total
- English / Chinese switch
- Browser localStorage persistence
- Reset Demo

This is a simplified static portfolio build of the original Next.js + Supabase prototype.
